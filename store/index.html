2Open the dashboard and add the package

  1. Open chrome.google.com/webstore/devconsole signed in as snomiao@gmail.com.
  2. If "Tomato Life" is already in the item list (ID kkacpbmkhbljebmpcopjlgfgbgeokbhn, the listing the README links to): open it → Package → Upload new package → drop TomatoLife-1.4.2.zip. This keeps the old ID, users and reviews.
  3. Otherwise: + New item → drop TomatoLife-1.4.2.zip.

The old listing no longer serves a version to Chrome, so it's probably unpublished or was taken down with the MV2 extensions.

3Store listing tab

Name and summary come from the manifest. Fill in the rest:

Graphic assets: drop store-icon-128.png on Store icon, both screenshot-*.png on Screenshots, and small-promo-tile-440x280.png on Small promo tile. Leave the marquee tile empty.

4Privacy tab

Data usage: tick none of the data types, then tick all three certifications:

  • I do not sell or transfer user data to third parties, outside of the approved use cases
  • I do not use or transfer user data for purposes that are unrelated to my item's single purpose
  • I do not use or transfer user data to determine creditworthiness or for lending purposes

The dashboard requires a privacy policy URL even though nothing is collected. The one above says exactly that.

5Distribution tab, then submit

  • Payments: Free of charge
  • Visibility: Public
  • Regions: All regions

Then click Submit for review. If the button is greyed out, the dashboard lists the missing fields in red. A new or unverified account also needs its contact email verified on the Account page first.
